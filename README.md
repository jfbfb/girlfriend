# 情侣浪漫网页

纯前端 HTML + CSS + JavaScript，无需后端。照片保存在本机 IndexedDB，不会上传到任何服务器。

## 使用方式

1. 用浏览器打开 **`index.html`**（推荐 Chrome / Edge）
2. 点击或拖拽上传多张照片，点击「准备好了」
3. 进入主视觉页，照片像气球漂浮；鼠标击打会向反方向弹飞，并与其它照片、边界真实碰撞
4. **按住空格**：照片在屏幕中央组成爱心边框（数量不够会自动复制同款补全）
5. **按住 A–Z 或 0–9**：照片组成对应字母/数字（实心填充）；松开按键恢复自由飘动
6. **按住 Shift 再触发形状键**：进入高规整模式，字形更工整
7. **左键点击照片**：烟花爆炸并显示情话，约 3 秒后淡出并重生同款照片
8. 右上角 **+** 可追加照片，**规则**按钮可查看完整玩法说明

## 说明

- 建议单次上传不超过约 50 张，每张小于 5MB，以免超出浏览器存储配额
- 字体依赖 Google Fonts，离线时会自动使用系统衬线字体
